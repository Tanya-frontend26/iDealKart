# iDealKart

A responsive iPhone e-commerce website built with React, focused on product showcase and WhatsApp ordering.

## 🚀 Live Demo

https://idealkart.netlify.app/

## ✨ Features

- Responsive design for desktop and mobile
- iPhone 17 Pro product showcase
- Multiple storage options
- Product pricing and offers
- WhatsApp-based ordering
- Clean and modern UI
- Easy navigation

## 🛠️ Tech Stack

- React
- JavaScript
- HTML
- CSS
- Netlify

## 📌 Project Overview

iDealKart is a responsive product showcase website designed for displaying iPhone products with pricing, storage options, and a simple WhatsApp-based ordering process.
